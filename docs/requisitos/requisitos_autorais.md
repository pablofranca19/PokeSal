# Requisitos autorais

| RA-01 | Dano crítico: (1/16 (6.25%) de chance de causar o dobro de dano em qualquer ataque que causa dano) |
| RA-02 | STAB (Same Type Attack Bonus): ao usar um ataque que causa dano do mesmo tipo do seu pokéSal, o dano aumenta em 50%) | 
| RA-03 | Ataques que alteram atributos: certos movimentos diminuem/aumentam atributos importantes do pokésal (ex: rosnar diminui ataque do adversário, retirada aumenta a própria defesa). essas mudanças são apenas para a batalha ativa, reiniciando quando a mesma acaba |
| RA-04 | clima/terreno é manipulado por movimentos: certos ataques como dança da chuva ou dia ensolarado mudam o clima/terreno para aquele correspondente ao tipo do ataque (poça e asfalto quente, respectivamente) |
