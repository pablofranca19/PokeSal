# Requisitos autorais

| Código | Requisito |
| --- | --- |
| RA-01 | Dano crítico: 1/16 (6,25%) de chance de causar o dobro de dano em qualquer ataque que causa dano. |
| RA-02 | STAB (Same Type Attack Bonus): ao usar um ataque que causa dano do mesmo tipo do seu pokéSal, o dano aumenta em 50%. |
| RA-03 | Ataques que alteram atributos: certos movimentos diminuem ou aumentam atributos importantes do pokéSal (ex.: Rosnar diminui o ataque do adversário; Retirada aumenta a própria defesa). |
| RA-04 | Clima/terreno é manipulado por movimentos: certos ataques, como Dança da Chuva ou Dia Ensolarado, mudam o clima/terreno para aquele correspondente ao tipo do ataque (poça e asfalto quente, etc.). |
